# 🚀 Edemy

A **modern and scalable Learning Management System (LMS)** built to enhance digital education experiences for students, instructors, and administrators.

🔗 **Repository:** https://github.com/Aditya130807/Edemy

---

## 📖 Project Overview

This project is developed as a full-stack application for an EdTech platform. It solves common problems in online learning such as:

* Poor course organization
* Low student engagement
* Weak authentication & security
* Inefficient user and content management

The platform provides a **seamless, responsive, and interactive experience** across all devices.

---

## ✨ Features

### 👨‍🎓 Student Features

* Browse & enroll in courses
* Track progress & completion
* Watch video lectures & access resources
* Submit assignments
* Participate in discussions

### 👨‍🏫 Instructor Features

* Create & manage courses
* Upload videos, notes, and assignments
* Track student performance
* Manage course content dynamically

### 🛠️ Admin Features

* User management (students/instructors)
* Course moderation
* Platform analytics & reports
* Role-based access control

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Aditya130807/Edemy
cd Edemy
````

### 2. Install Dependencies

```bash
# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

> Note: If you add or update backend packages, run `npm install` again inside `server/` before starting the server.

### 3. Setup Environment Variables

Create a `.env` file in the server directory:

```
PORT=5000
MONGO_URI=your_database_url
JWT_SECRET=your_secret_key
```

### 4. Run the Application

```bash
# Backend
cd server
npm run dev

# Frontend
cd client
npm start
```
